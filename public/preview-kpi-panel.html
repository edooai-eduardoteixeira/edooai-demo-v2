What changed

  • Trust-period filtering: Sparklines start from thresholdDay (day 8 at $150K) instead of day 1. Removes extreme outliers naturally — no more $6,503 CAC on day 2.
  • Wider aspect ratio: SVG changed from 40×16 to 60×16 (~4:1 ratio). Trend is easier to read.
  • Trailing dot: Small circle at the endpoint (Robinhood pattern). Marks "where we are now."
  • Color coding: Green = improving trend, red = worsening. CAC is inverted (lower is better).
  • 3-point smoothing: Moving average removes day-to-day noise, highlights overall trend.
  • Day range labels: Visible text below each KPI: "Day 8: $880 → Day 30: $289" (replaces hidden browser tooltip).
  • Info icon + tooltip: Hover over ⓘ next to KPI name to see definition. Uses existing Tooltip component.
